# Cafe7

A modern web application for Cafe 7, featuring digital menu browsing, food showcase, and interactive ordering interface built with Next.js, React, Tailwind CSS, and Framer Motion.

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
